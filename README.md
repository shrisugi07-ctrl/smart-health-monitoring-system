# 🩺 Smart Health Monitoring System

An AI-powered Smart Health Monitoring System designed to analyze health-related data and provide machine learning-based risk predictions.

## 📌 Overview

This project combines data analysis, machine learning, and a user-friendly health monitoring interface to support health-risk assessment.

## ✨ Key Features

- 📊 Exploratory Data Analysis (EDA)
- 🤖 Machine Learning-based health-risk prediction
- 🩺 Health monitoring interface
- 📈 Model performance evaluation
- 💧 Waterborne disease prediction
- 📋 Classification reports and confusion matrices
- 📉 Data visualization and analysis

## 🧠 Project Components

### ❤️ Health Risk Prediction
The system uses health-related features to train machine learning models for predicting health-risk conditions.

### 💧 Waterborne Disease Prediction
A separate machine learning component is used for waterborne disease-related prediction.

### 📊 Data Analysis
The project includes exploratory data analysis, visualizations, model evaluation, and performance metrics.
