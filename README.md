# 🩺 Smart Health Monitoring System

### AI-Powered Health Risk & Waterborne Disease Prediction

A machine learning-based system for analyzing health-related data and providing predictive insights.

</div>

---

## 📌 Overview

The **Smart Health Monitoring System** combines data analysis, machine learning, and a user-friendly interface to support health-risk assessment and prediction.

The project includes health-risk prediction, waterborne disease prediction, exploratory data analysis, model training, and model evaluation.

---

## ✨ Key Features

* 📊 Exploratory Data Analysis (EDA)
* 🤖 Machine Learning-based health-risk prediction
* 💧 Waterborne disease prediction
* 📈 Model performance evaluation
* 📋 Classification reports
* 🔍 Confusion matrix analysis
* ⚙️ Hyperparameter analysis
* 🖥️ Health monitoring interface
* 📉 Data visualization

---

## 🧠 Project Components

### ❤️ Health Risk Prediction

The system analyzes health-related features and applies machine learning techniques to identify patterns associated with different health-risk conditions.

The workflow includes:

* Data preprocessing
* Exploratory data analysis
* Feature selection
* Model training
* Model evaluation
* Prediction

### 💧 Waterborne Disease Prediction

A separate machine learning component analyzes relevant water and health-related parameters for waterborne disease prediction.

The project includes a trained model:

`water_disease_model.pkl`
